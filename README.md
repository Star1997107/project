# project
Тренировочный план
\*\*Автор:\*\* \[Егор Деревенских]



\## Описание

Приложение для удобного планирования и отслеживания спортивных тренировок.

Позволяет записывать дату, тип активности и время, а также фильтровать историю записей.



\## Функционал

\- Сохранение данных в JSON.

\- Валидация корректности ввода даты и чисел.

\- Фильтрация по дате и типу тренировки.



\## Использование

1\. Запустите файл `main.py` через Python 3.

2\. Введите данные в верхнюю форму и нажмите "Добавить".

3\. Для поиска используйте поля в секции "Фильтрация".
